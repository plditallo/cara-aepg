# AEPG v0.3 Coordinated Release

This package contains the coordinated normative revision produced from Reference Implementation v0.2 findings:

- AEPG Technical Specification v0.3
- AEPG Semantic Validation Profile v0.3
- consolidated JSON Schema Draft 2020-12 catalog v0.3
- Constraint Registry v0.3
- Side-Effect Class Registry v0.3
- v0.2 → v0.3 Migration Guide

Reference Implementation v0.2 remains a separate executable artifact. Its 74-test adversarial suite is the implementation evidence motivating this revision.
